# Life OS

**Everything in Your Life, All in One Place.**

Life OS is an all-in-one personal organization dashboard designed to help you manage everyday life. Keep track of your tasks, organize your calendar, write notes, and set reminders through one clean and modern interface.

## Features

- Personal overview dashboard
- Task management and organization
- Calendar for events and scheduling
- Notes for saving ideas and important information
- Reminders for upcoming tasks and events
- Clean and modern user interface
- Responsive mobile-friendly design
- Organized navigation between sections
- Simple and easy-to-use layout

## Technologies

- HTML5
- CSS3
- JavaScript

## Deploy with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Click **Save**.
6. Wait for GitHub Pages to finish deploying.

The homepage must be named `index.html` and placed in the repository root.

## Updating the Website

Edit `index.html` and commit the changes to the `main` branch. GitHub Pages will publish the updated site automatically.
